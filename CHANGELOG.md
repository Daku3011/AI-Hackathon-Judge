# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-12-25

### Added
- Initial release of AI Hackathon Judge
- Deep repository analysis feature to assess project quality
- YouTube video transcript analysis for demo pitch evaluation
- Multiple judge personas:
  - Standard: Balanced feedback
  - The VC: ROI and scale-focused evaluation
  - The CTO: Code quality and technical depth assessment
  - Roast Master: Brutal and humorous technical feedback
- Modern glassmorphic UI with light theme
- React-based frontend with Vite and Tailwind CSS v4
- Python FastAPI backend with Google Gemini AI integration
- Docker support with docker-compose configuration
- Asynchronous judge engine with direct JSON parsing
- "Why You Won't Win" reality check feature
- Roast feature for invalid inputs
- Configurable frontend API URL
- Comprehensive scoring system
- Real-time feedback generation

### Tech Stack
- **Frontend**: React 19.2, Vite 7.2, Tailwind CSS 4.1
- **Backend**: Python 3.10+, FastAPI, Google Gemini AI
- **Deployment**: Docker, Docker Compose

### Requirements
- Node.js v18+
- Python v3.10+
- Google Gemini API Key
